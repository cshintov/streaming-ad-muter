# Streaming Ad Muter

Chrome extension to automatically mute ads on Hotstar and SonyLIV.

## Features
- Automatically detects ads
- Mutes tab during ads
- Optional black overlay during ads
- Countdown timer showing remaining ad duration
- Restores volume when ad ends
- Supports both regular content and live cricket matches

## Installation
1. Open Chrome Extensions (chrome://extensions/)
2. Enable Developer Mode
3. Click "Load unpacked"
4. Select this directory

## Privacy
This extension:
- Does not collect any user data
- Does not communicate with external servers
- Only monitors network requests on supported streaming platforms
- All processing happens locally in your browser
